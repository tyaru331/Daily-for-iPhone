# Daily+（第1版）

## できること
- 今日のタスク追加・完了・削除と達成率
- 月間カレンダーで日付ごとの予定を確認
- 毎日の習慣チェック
- 日記・振り返りの保存
- ChatGPTにスケジュール作成を依頼するためのプロンプト生成
- ページを開いている間のブラウザ通知（許可が必要）
- JSONでデータのバックアップ・復元
- PWAとしてホーム画面に追加、オフラインキャッシュ

## iPhoneで使う方法
このZIPをHTTPS対応の静的ホスティング（例：GitHub Pages）に配置して公開します。
公開したURLをiPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」を選びます。
ローカルファイルを直接開くだけではPWA機能や通知が動作しません。

## 無料公開の一例：GitHub Pages
1. GitHubにログインし、新しいPublicリポジトリを作成
2. ZIPを展開し、中の5ファイル（index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png）をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → main / root → Save
4. 表示されたURLをiPhone Safariで開く
5. 共有 → ホーム画面に追加

## 現時点の制限
- AI生成はChatGPTに依頼文をコピーして貼り付ける方式（API連携ではありません）
- 通知はアプリの画面が開いている間だけ。バックグラウンドの確実な通知は未実装
- データは端末内のブラウザ保存。端末間同期・アカウント・クラウドバックアップなし
- 日付ごとの予定の追加は現状「今日」画面からのみ
